# System Overview

## Mục tiêu

AI Hedge Fund OS là một hệ điều hành AI đa tác nhân (Multi-Agent AI Operating System).

Hệ thống không tự ý giao dịch.

Nhiệm vụ của hệ thống là:

- Thu thập dữ liệu
- Làm sạch dữ liệu
- Phân tích dữ liệu
- Đánh giá rủi ro
- Đề xuất chiến lược
- Lưu nhật ký
- Tạo báo cáo

Quyết định cuối cùng luôn thuộc về người dùng.

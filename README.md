# AI Hedge Fund OS

> Open Source AI Operating System for Crypto, Forex and Stock Market.

## 🚀 Mục tiêu

Xây dựng một hệ thống AI đa tác nhân (Multi-Agent AI) có khả năng:

- Thu thập dữ liệu từ nhiều nguồn.
- Phân tích thị trường Crypto.
- Phân tích Forex.
- Phân tích kinh tế vĩ mô.
- Đánh giá rủi ro.
- Hỗ trợ ra quyết định.
- Ghi nhật ký giao dịch.
- Tạo báo cáo tự động.
